# Nemoto Works Web Portal

Nemoto Worksの公開用ポータルです。既存のPrivateリポジトリ `nemoto-works/workspace` とは分離して管理します。

## Local preview

静的ファイルだけで動作します。任意の静的Webサーバーでこのディレクトリを配信してください。

## Publish checklist

- お問い合わせ先を確定する
- プライバシーポリシーを実運用に合わせて更新する
- 独自ドメインを決める
- Cloudflare Web Analytics / Google AdSenseの採用有無を反映する
- 公開前にリンクとスマートフォン表示を確認する
