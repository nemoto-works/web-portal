# 切替

仕事・家族・学習・休息を選び、スイッチと短い言葉で次の時間へ気持ちを切り替える道具。

元アプリ: https://kirikae-switch.nemoshin.chatgpt.site/

2026-10-16、所有者の指示により公開済みのHTML・CSS・クライアント動作を確認し、Nemoto Worksの管理資産として移植。Sitesの元ソース取得は利用できなかったため、Reactの実行基盤を含めず、読めるJavaScriptとして動作を再実装した。CSSは公開版から引き継いだ（先頭のTailwind MIT表記を保持）。

## 構成

- `index.html`: 日本語の画面とポータルへの導線
- `styles.css`: 元アプリの3種類のスイッチとレスポンシブ表示
- `app.js`: モード選択、ランダムな言葉、ON/OFF、選択モードの端末保存

ログイン、外部通信、計測、ビルドは不要。保存内容はこのアプリ専用キーの選択モードのみ。保存できない環境でも動作する。ポータル全体への影響を避けるため、元アプリのルートService Workerとインストール用manifestは移植していない。オフライン動作は保証しない。

## 確認方法

リポジトリを静的配信し `/lab/kirikae-switch/` を開く。

1. 仕事・家族・学習・休息を選択し、開始前の表示に戻ること。
2. スイッチを押すと対応する言葉と「切り替えました。」が表示され、再度押すとOFFになること。
3. 再読み込みで選択モードが残り、ON状態は残らないこと。
4. Tab・Space・Enterで操作でき、スマートフォンの縦横で操作部が見えること。
5. LABへの戻りリンクが機能すること。

リポジトリ共通検証: `node scripts/validate-lab.mjs`
