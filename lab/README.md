# Nemoto Works LAB

Webポータル内の試作品確認スペース。オーナーはGitHubのPRではなくスマホで動くURLを確認する。

## 運用
- `lab/<app-slug>/` に独立した静的試作を配置
- 掲載前に機密情報・ライセンス・依存API・セキュリティをAI側で確認
- 企画・実装・コードレビュー・Git操作はAI側で実施
- 公開サイトへの反映はオーナーの明示承認を得てから実施
- LABに掲載するものは一般公開であり、アクセスが少なくても非公開ではない
- 今回の追加は開発ブランチ上。デプロイしない

## 注意
GitHub Actionsやホスティング設定次第ではmainへのマージが即時公開になるため、承認前にマージしない。
