# Nemoto Works LAB

ホームページ内の一般公開可能な試作品スペース。オーナーはGitHub操作をせず、スマホで動作を確認する。

## 公開権限（2026-10-16 承認）
- **LAB内の試作品**: AIが機密・権利・安全性・表示内容を確認したうえで自動公開してよい
- **正式リリース・販売・LAB以外の公開変更**: 必ず事前にオーナーの承認を得る
- `lab/<app-slug>/` に静的な試作を配置。公開されるため個人情報・秘密情報・認証情報は含めない
- 公開前にテスト結果・リンク・リスクを記録。テスト未実施の場合は未実施と明示
- PR・マージ・デプロイなどのGit操作はAI側で実施
- LABは一般公開。アクセス数が少なくても非公開ではない

## 今回の範囲
LAB内ページと試作品のみ。ホームページのナビゲーションなどLAB外は変更しない。

## LAB卒業

試作品が専用の公開リポジトリへ昇格したら、公開作業と同じ変更単位で次を行う。

1. LAB一覧から試作品カードを削除する
2. 本番トップのアプリ一覧へ、公開版の説明と利用リンクを追加する
3. `lab/<app-slug>/index.html` の旧実装を、公開版URLへの軽量な転送ページへ置き換える
4. 転送ページの `html` 要素へ `data-lab-graduated` を付け、公開版のcanonical URLを記載する
5. LAB CIで「卒業済みアプリが一覧に残っていない」「公開版URLが本番トップにある」を検証する
6. 以後の開発は専用公開リポジトリで行い、LABへ本体コードを戻さない

旧URLはブックマークや共有リンクのために転送ページとして維持する。旧アプリ本体は二重管理しない。

## 公開履歴の更新ルール

- LABの `index.html` にある「開発・公開の歩み」はNemoto Worksのポートフォリオ記録。
- 新規プロダクトのLAB掲載または正式公開、主要な更新を行う際は、同じ変更で履歴にも日付・作品名・変更概要・利用URLを追加する。
- 新しい項目を先頭に置き、既存の記録は消さない。公開終了時も履歴を残し、リンク切れの場合は状況を明記する。
- 初回公開日の検証ができない場合、推測日付を載せない。GitHub main追加日の場合はその基準を明記する。
- 日付は日本時間（Asia/Tokyo）、`<time datetime="YYYY-MM-DD">` 形式で管理する。
