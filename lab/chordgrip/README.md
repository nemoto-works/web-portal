# ChordGrip LAB
スマホを横向きにして指位置をタップするギターコード練習試作。

Em / Am / C / G / D、開放・ミュート表示、合成音、6ステップの2音練習。各位置の確認方式で、同時押しや実ギターの演奏判定はしない。端末は左がヘッド側。

## 開発・確認
提供済みの自己完結HTMLを継承。旧試作と比較し、5コード版を採用。2026-10-18オーナー指示でLAB公開。以後のLAB試作修正の正本はこのディレクトリ。

```sh
cd lab/chordgrip
npm test
npm run build
```

Node.js 24推奨、外部依存なし。生成先distはローカル確認用。LABはindex.htmlを直接配信。

## テストと制約
模擬DOMと仮想タイマーの回帰テスト8件、構文検査・静的ビルド成功。コード切替・完成条件・連打・リセット・モード切替・音声なし・音声再開と周波数を確認。実端末での音、タッチ感、表示は追加確認が必要。

横向きで使用。音声は合成音で実ギターの音色ではない。再生キャンセル時、発音済みの短い音は自然減衰。学習履歴、実音認識、メトロノーム、多点同時押し判定は未実装。

## スマホでの確認
5コードを切り替えて全指位置をタップ。鳴らすで音を確認。例題を連打し1段階ずつ進むこと、途中でリセット・コード練習へ戻せることを確認。指の届き方・左右方向は今後調整。

外部素材・曲の録音・個人情報・認証・外部通信・保存機能なし。正式リリースと販売は別途承認。
