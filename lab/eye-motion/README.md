# Eye Motion LAB

奥の中心から3レーンへ迫る球を目で追い、黄色い輪に重なる頃にタップする、スマートフォン向けの短いゲーム試作です。

## 操作

1. `スタート` を押す
2. 球が向かうレーンを見て、黄色い輪に重なる頃に対応するボタンを押す
3. 約45秒ごとにゲームが止まったら、20秒間画面から視線を外して実際の遠景を見る

## ローカル起動

リポジトリ直下を任意の静的Webサーバーで配信し、`/lab/eye-motion/` を開きます。外部通信、ログイン、個人データ保存はありません。

## テスト

```sh
node --test lab/eye-motion/tests/engine.test.mjs
node scripts/validate-lab.mjs
```

## 既知の制約

- 音楽・効果音・譜面選択は未実装です。
- タップ判定と休憩間隔は固定です。
- 端末やブラウザごとの実機確認は人によるレビューが必要です。
- 本試作はゲームであり、視力改善などの医療効果を目的・保証しません。
