# 歴史のお隣誰だ？

日本史・世界史の出来事を、年代に比例した横スクロール年表の前後関係から答える静的クイズです。

- 日本史20件、世界史20件
- 出来事を古い順に1件ずつ穴埋め
- 正解後に年代・短い解説・確認元を表示
- 日本史／世界史ごとに進捗をブラウザへ保存
- 復習、進捗リセット、スマートフォンの横スクロールに対応
- 外部API、ログイン、個人情報の入力、アクセス解析なし

## 確認

```sh
python3 -m unittest discover -s lab/history-neighbors -p 'test_*.py' -v
node scripts/validate-lab.mjs
```

静的テストに加え、スマートフォン幅でモード切替、4択、正解表示、次の問題、復習、横スクロールを確認します。

## 出典

年代と説明は、国立公文書館「歴史と物語」「日本のあゆみ」、World History Encyclopedia、The Metropolitan Museum of Art の年表を照合し、学習用に短く要約しています。年代に諸説がある出来事は一般的な教科書表記とし、「約」を付けています。
